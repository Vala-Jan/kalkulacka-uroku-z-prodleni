# Kalkulačka na výpočet úroku z prodlení

Oproti jiným kalkulačkám na webu zpracovává faktury k zadanému datu splatnosti hromadně a nabízí i export do excelu. Má funkce jako ostatní webové kalkulačky: výběr datumu splatnosti, přehledný dashboard atd.
Disponuje funkcí "Předžalobní výzva pro dlužníka", která generuje layout předžalobní výzvy (PDF a Word). 

# Formát

Navrhnuto pro systém GINIS a jeho přímé exporty. Přijímá .xlsx, .xls a .csv.
